## 1. 한 줄

서경대생이 **수강신청을 준비하는 곳**. 시간표를 짜고, 졸업요건을 맞추고, 신청을 연습한다.

빈 교시에 강의 찾기는 그 안의 **탐색 도구**일 뿐, 사이트를 만든 이유가 아니다.

## 2. 왜 만드나

수강신청은 한 번의 클릭이 아니라 준비 과정이다.

- 어떤 조합이 겹치지 않는지 (시간표)
- 전공·교양·학점이 졸업에 맞는지 (졸업요건)
- 신청 날 헤매지 않게 미리 눌러 보는지 (시뮬레이션)
- 포털만으로는 조합·연습·요건이 흩어져 있다

예전 문구(「빈 교시를 고르면 그 칸의 강의만 남는다」)는 차별 기능 하나를 제품 정의로 키워 버렸다. v0.3부터는 버린다.

## 3. 핵심 축 (우선순위)

| 축 | 하는 일 | MVP |
|---|---|---|
| **시간표** | 분반을 담고, 충돌·학점을 보고, 안을 저장한다 | P0 |
| **졸업요건** | 전공/교양/학점 칸을 채우며 「아직 부족한 것」을 본다 | P1 (화면·규칙은 P0에 자리만) |
| **신청 시뮬** | 장바구니 → 모의신청 순서를 연습한다. 매크로·실제 신청 대행 아님 | P1 |
| **신청 도움** | 학기 체크리스트, 과목 요령, 포털과 병행 안내 | P0 |
| 탐색(보조) | 이름/교수/학점 검색. 빈 교시 필터는 여기 속한다 | P0 검색, 위시필터는 P1 |

## 4. 한다 / 안 한다

**한다**

1. 학기 강의 데이터(CSV/엑셀)로 과목·분반 조회
2. 주간 시간표 보드, 담기, 충돌, 학점, 저장
3. 과목 탐색(검색·필터). 빈 교시는 필터 중 하나
4. 관심 과목, 짧은 선배 요령
5. 신청 도움: 「담기 → 확인 → 포털에서 신청」 흐름 안내
6. 졸업요건 칸 UI (데이터는 수동/시드부터)
7. 모의신청: 내 장바구니로 순서 연습 (서버 시계, 클릭 연습)

**안 한다**

- 공식 수강신청 대행, 매크로, 포털 해킹성 연동
- 실시간 여석 크롤·알림 (학교 협조 전)
- 공강메이트·중고·지원금 (투표 2등, 별도)

## 5. 사용자 흐름

1. 로그인 · 학기 선택
2. **요건** — 이번 학기 채울 학점/영역 확인 (없어도 시간표는 진행)
3. **탐색** — 과목 찾기 (검색이 기본, 빈 교시는 옵션)
4. **시간표** — 담고 충돌·학점 맞추기. 안 A/B
5. **시뮬** — 담은 과목으로 모의신청 연습
6. **도움** — 체크리스트·요령 보고 실제 포털로

홈 카피는 시간표·요건·연습이지, 빈 교시 히어로가 아니다.

## 6. 기능 우선순위

### P0 MVP

- 계정, 학기 과목 DB, 검색
- 시간표 보드 / 담기 / 충돌 / 학점 / 저장
- 관심 과목, 요령 조회
- 신청 도움 카피·체크리스트
- 관리자 임포트, 비공식 고지

### P1

- 졸업요건: 영역별 이수 칸, 부족 과목 힌트
- 모의신청 연습 화면
- 위시 교시 필터 (탐색의 하위)
- 시간표 여러 안, 프로필(전공·학년)

### P2

- 공식 데이터·여석 (협조 후)
- 요건 PDF/학과별 자동 분석
- 시간표 공유, 관심 인원 집계

## 8. 규칙

- 충돌: 요일·시간 구간이 겹치면 충돌
- 같은 과목 다른 분반 중복 담기 금지
- 시뮬은 연습이다. 실제 정원·여석을 보장하지 않음
- 요건 데이터도 참고용. 학적 공식 결과가 아님
- 빈 교시 매칭은 「교집합」을 기본 (킥오프에서 확정)
