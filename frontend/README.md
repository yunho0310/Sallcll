# Frontend

프런트엔드 애플리케이션이 들어갈 자리입니다. 아직 프레임워크가 정해지지 않아 뼈대만 있는 상태입니다.

## 시작하기 (예정)

1. 프레임워크 선정 (예: React + Vite, Next.js 등)
2. `npm create vite@latest . -- --template react-ts` 또는 `npx create-next-app@latest .` 등으로 스캐폴딩
3. `package.json`의 `dev`/`build` 스크립트를 실제 스크립트로 교체
4. 루트에서 `npm run dev:fe` / `npm run build:fe`로 실행

백엔드는 [`../backend`](../backend)에 있으며, API는 기본적으로 `/api` 접두사를 사용합니다.
