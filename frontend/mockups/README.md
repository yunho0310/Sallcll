# 본 시안 (정적 HTML)

팀이 확정한 메인 시각. 스캐폴드 전 브라우저로 연다.

## 여는 법

```bash
start frontend/mockups/home.html
```

| 파일 | 화면 |
|---|---|
| `home.html` | 홈 히어로 · 로그인 · 회전문 · 카탈로그 |
| `table.html` | 내 시간표 |
| `req.html` | 졸업요건 |
| `sim.html` | 모의신청 |
| `help.html` | 신청 도움 |

토큰: `blend-tokens.css` (라이트, 액센트 `#03C75A`).

예전 테마 시안(네이버·토스·Apple 등)은 본 시안 확정 후 삭제했다.
