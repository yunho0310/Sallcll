# 메인 시안 (팀 투표용)

프레임워크 스캐폴드 전에 보는 **정적 HTML**입니다. 서버 없이 브라우저로 엽니다.

## 팀원이 보는 방법

1. 이 저장소를 클론한다.
2. `frontend/mockups/themes/index.html` 을 더블클릭하거나:

```bash
start frontend/mockups/themes/index.html
```

3. 목록에서 시안을 **하나씩** 연다. (한 페이지에 모아 두면 차이가 잘 안 보인다.)

| 파일 | 참고 |
|---|---|
| [toss.html](./themes/toss.html) | 토스 |
| [naver.html](./themes/naver.html) | 네이버 포털 |
| [everytime.html](./themes/everytime.html) | 에브리타임 게시판 |
| [apple.html](./themes/apple.html) | Apple |
| [stripe.html](./themes/stripe.html) | Stripe |
| [notion.html](./themes/notion.html) | Notion |
| [airbnb.html](./themes/airbnb.html) | Airbnb |
| [linear.html](./themes/linear.html) | Linear |
| [cal.html](./themes/cal.html) | Cal.com |
| [kakao.html](./themes/kakao.html) | 카카오톡 |

탐색 필터 데모는 [`../demo/index.html`](../demo/index.html) 입니다. 시안 투표용이 아닙니다.
